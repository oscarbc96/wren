title: Roadmap
description: Milestones from M0 to M7 and the public alpha, in plain language.
---

Wren is delivered milestone by milestone. Each one ends with something usable
and measured.

## M0: Shell

Window, tabs, omnibox, history, bookmarks, embedded Servo with one process
per tab, crash recovery. RAM benchmark and web-platform-tests harness running in CI. Docs site skeleton.

## M1: Daily driver

A task manager to end any tab's process, a hang watchdog, tab sleep and
freeze, ad blocking, passwords in the macOS Keychain plus Chrome
import, downloads, "Open in Chrome", top-sites harness, DevTools through
Servo's existing remote debugging. Builds are ad-hoc signed for local use.

## M2: Chrome DevTools

CDP server, bundled Chrome DevTools frontend, Playwright and Puppeteer support.

## M3: Extensions core

Install from the Chrome Web Store, content scripts, core `chrome.*` APIs,
extension harness. 1Password, Bitwarden, uBlock Origin Lite and Dark Reader.

## M4: AI core

Providers, AI sidebar, agent with safety rules, MCP, WebMCP.

## M5: Generated pages

Search providers, reader, OpenUI pipeline, pin and refresh.

## M6: Routines

Detection, recipes, scheduler, confirmations, menu-bar agent.

## M7: Plugins

WebAssembly plugins.

## Public alpha

Signed, notarized macOS build, auto-update, docs, public parity dashboard,
passkeys. Needs an Apple Developer account.
