---
title: DevTools
description: Inspect pages with Servo's remote debugging server and Firefox DevTools.
---

Wren can expose Servo's remote debugging server so you can inspect pages
with Firefox DevTools. The server only ever listens on `127.0.0.1`.

## Turn it on

- For one run: start Wren with `--devtools` (port from settings) or
  `--devtools 6123`.
- Always: set `"devtools": { "enabled": true }` in `settings.json`, or press
  `Cmd+Alt+I`, which saves that setting for you.
- Port: `devtools.port`, default `6000`.

Servo 0.8 starts its debugging server only when the engine starts, so
`Cmd+Alt+I` takes effect on the next launch. The toolbar shows
"DevTools on :6000" while the server runs and says when a change waits for
a restart.

## Connect from Firefox

1. Start Wren with DevTools on.
2. In Firefox, open `about:debugging`, then Setup.
3. Add the network location `127.0.0.1:6000` (use the IP: on macOS
   `localhost` can reach the AirPlay receiver instead).
4. Connect and pick the tab to inspect.
