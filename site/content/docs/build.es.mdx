Wren todavía no se puede compilar. El primer hito (M0) no se ha publicado, así
que no hay árbol de código que compilar ni requisitos que instalar.

## Qué esperar

Cuando llegue M0, esta página listará la cadena de herramientas admitida, los
comandos de compilación y la configuración de firma necesaria para ejecutar una
compilación local en macOS. Hasta entonces, sigue la
[hoja de ruta](/wren/es/docs/roadmap/) para conocer el progreso.
