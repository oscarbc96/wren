Wren es de código abierto bajo MPL-2.0. Las contribuciones son
bienvenidas.

## Antes de empezar

- Lee la especificación de diseño y la hoja de ruta del repositorio.
- Firma el Acuerdo de Licencia de Colaborador (CLA). El mantenedor es Oscar
  Blanco (GitHub: @oscarbc96).
- Sigue el flujo descrito en `AGENTS.md` para commits, pruebas y revisiones.

## Cómo contribuir

1. Abre una incidencia describiendo el cambio.
2. Haz un fork del repositorio y crea una rama.
3. Realiza el cambio con pruebas.
4. Abre una solicitud de extracción.
