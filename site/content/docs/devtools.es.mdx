---
title: Herramientas de desarrollo
description: Inspecciona páginas con el servidor de depuración remota de Servo y las herramientas de Firefox.
---

Wren puede exponer el servidor de depuración remota de Servo para que puedas
inspeccionar páginas con las herramientas de desarrollo de Firefox.

## Activar herramientas de desarrollo

- Alternar: `Cmd+Alt+I`
- Ajuste: `devtools.port` (predeterminado: `7000`)
- Dirección de escucha: siempre `127.0.0.1:<port>` (solo bucle local)

En Servo 0.8, el servidor de herramientas de desarrollo se inicia solo cuando
el motor se inicializa. Cambiar la preferencia en tiempo de ejecución no inicia
ni detiene el servidor en la sesión actual, por lo que Wren aplica el ajuste en
el próximo inicio. El indicador de la barra de herramientas te avisa cuando se
aplicará en el próximo inicio.

## Conectar desde Firefox

1. Activa las herramientas de desarrollo en Wren (`Cmd+Alt+I`).
2. Reinicia Wren si el indicador muestra que el ajuste se aplicará en el
   próximo inicio.
3. Abre `about:debugging` en Firefox.
4. Añade una ubicación de red para `localhost:7000` (o el puerto configurado).
5. Conéctate e inspecciona la página.
