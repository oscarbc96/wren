Wren is not buildable yet. The first milestone (M0) has not shipped, so there
is no source tree to build and no prerequisites to install.

## What to expect

When M0 lands, this page will list the supported toolchain, the build commands
and the signing setup needed to run a local build on macOS. Until then, follow
the [roadmap](/wren/docs/roadmap/) for progress.
