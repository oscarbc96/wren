Wren is open source under AGPL-3.0-or-later. Contributions are welcome.

## Before you start

- Read the design spec and the roadmap in the repository.
- Sign the Contributor License Agreement (CLA). The maintainer is Oscar Blanco
  (GitHub: @oscarbc96).
- Follow the workflow described in `AGENTS.md` for commits, tests and reviews.

## How to contribute

1. Open an issue describing the change.
2. Fork the repository and create a branch.
3. Make your change with tests.
4. Open a pull request.
