# M0 Shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `mise run run` opens a GPUI browser window with tabs, an omnibox,
back/forward/reload, history and bookmarks. Pages render with Servo, and
the session survives a crash or quit. A RAM benchmark against Chrome and a
WPT parity run work from `mise` tasks and CI.

**Architecture:** `engine` is the only crate that touches Servo. It exposes
`Engine`/`EngineEvent` and a `FakeEngine` for tests. `tabs` is a pure
model driven by engine events. `store` keeps history, bookmarks and the
session in SQLite. `omnibox` decides between URL and search and gives
suggestions. The `wren` binary is the GPUI app that wires them together
and hosts each Servo view as a child NSView. Tooling, `settings` and
`themes` are copied from the template.

**Tech Stack:** Rust (edition 2024, toolchain 1.100), `servo` `=0.8.0`
(crates.io, MPL-2.0), GPUI-CE from crates.io: `gpui` (package `gpui-ce`
`=0.3.0`), `gpui_platform` (package `gpui_ce_platform` `=0.3.0`),
`gpui_elements` (package `gpui_ce_elements` `=0.3.0`), all Apache-2.0, `raw-window-handle` 0.6, `objc2-app-kit`, `rusqlite` 0.42.0
(`bundled`), `rusqlite_migration` 2.7.0, `url` 2, `psl`, `idna`,
`unicode-script`, `jiff` 0.2, `sysinfo`, `clap` 4, `serde`/`serde_json`,
`thiserror`/`anyhow`, `insta`, `cargo-nextest`; mise, hk 2.12.0, Bun
(site).

**Spec:** `docs/superpowers/specs/2026-11-13-wren-browser-design.md`
(sections 5, 5b, 5c, 7.1, 7.2, 7.3, 9, 10 M0, 11).
Roadmap: `docs/superpowers/plans/2026-11-13-roadmap.md`.
Source of copied tooling and crates: the owner's template repo. Its path is
given in the task brief and is never written into this repo. Copy, then
rename the template's binary, env prefix and URI scheme to `wren`, `WREN_`,
`wren://`.

## Global Constraints

- License `AGPL-3.0-or-later` in every `Cargo.toml` and `site/package.json`;
  docs CC-BY-4.0; copied template files keep their headers and are
  listed in `NOTICE`.
- `cargo deny` uses the template's `deny.toml` allow list. Obscura's stealth build
  (BoringSSL) is never a dependency.
- Crate names: `wren` (binary), `engine`, `tabs`, `store`, `omnibox`,
  `settings`, `themes`, `components`, `parity`. Only `engine` depends on
  `servo`.
- Platform: macOS 14+ on Apple Silicon only. CI runs on `macos-latest`.
- Config dir `~/.config/wren` (override `WREN_CONFIG_DIR`); data dir
  `dirs::data_dir()/wren` (override `WREN_DATA_DIR`). Tests always set both.
- Never use "Chrome", "Google" or "Servo" in product, binary or app names.
- No telemetry and no network calls except page loads the user asks for,
  and the benchmark and WPT tasks.
- Every task lands as a self-merged squash PR with a Conventional Commit
  title; commits are signed; local `mise run lint` and `mise run test`
  green first (AGENTS.md, copied from the template).
- Defaults: search URL `https://duckduckgo.com/?q={query}`; new tab URL
  `about:blank`; restore session on start `true`; closed-tab stack 25.

## Review Focus

1. **Ambiguous omnibox input** (`localhost:3000`, `192.168.1.1`,
   `[::1]:8080`, `foo.local`, `what is rust`, `rust.lang`): a person
   expects local addresses to load and sentences to search. Pinned by
   `classify_table` (Task 7).
2. **A content crash in the single process** must leave the app and other
   tabs running and offer Reload in that tab. Pinned by
   `crashed_tab_reloads_with_new_webview` (Task 6) and the spike's crash
   check (Task 2).
3. **Quit or power loss during a session save** must restore the last
   good session, never an empty window. Pinned by
   `session_save_is_atomic` (Task 5).
4. **Look-alike hosts** (Cyrillic `аpple.com`) must show as punycode in
   the omnibox. Pinned by `display_host_mixed_script_is_punycode` (Task 7).
5. **Big history** (100k visits) must keep omnibox suggestions fast.
   Pinned by `suggest_100k_under_20ms` (Task 7, perf-ignored test run by
   `mise run test:perf`).
