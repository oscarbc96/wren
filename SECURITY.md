# Security policy

## Reporting a vulnerability

Please report security issues privately, not in public issues. Use GitHub's
private vulnerability reporting for this repository:
https://github.com/oscarbc96/wren/security/advisories/new

Include what you found, the steps to reproduce, and the affected version. You
should get a first reply within a week. Please give us reasonable time to fix
the issue before you disclose it.

## Scope

Wren handles your browsing session, local profile data and any AI provider
credentials you configure. Issues that expose those are the most important to
us.

## Supported versions

Only the latest release receives security fixes.
